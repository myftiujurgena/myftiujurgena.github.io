# Jurgena Myftiu · sito personale

Sito accademico statico (HTML/CSS/JS, nessuna build), bilingue italiano/inglese, pubblicato con GitHub Pages: https://myftiujurgena.github.io/

## Dove modificare
- **Testi**: `index.html` (le versioni IT/EN sono negli attributi `data-it` e `data-en`).
- **Pubblicazioni**: le schede in `index.html` **e** l'elenco `publications` in `app.js` (stesso ordine).
- **Presentazioni**: sezione `#presentazioni` in `index.html`.
- **Stile**: `styles.css`. **Foto e CV**: cartella `assets/` (stessi nomi file).

Ogni modifica salvata sul ramo `main` viene pubblicata in automatico in 1–2 minuti.
